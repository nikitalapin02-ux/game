ВСЕ ПОЖЕЛАНИЯ ПО ИГРЕ "НАШ ПУТЬ" — сводка по чату
====================================================

1. ПЕРСОНАЖИ (спрайты и анимация)
-----------------------------------
- Заменить кружок/плейсхолдер на настоящие пиксель-арт спрайты: Никита, Ксюша, Макс, Шемрок
- У Шемрока (мышь/дегу) переставить с плеча — пусть бежит за компанией по земле, а не сидит на плече
- Исправить баг: персонажи становятся почти невидимыми при ходьбе/беге (наложение полупрозрачных кадров анимации)
- У Ксюши обрезана/пропадает рука в некоторых кадрах при ходьбе — перенарезать спрайт-лист точнее (проблема была в нарезке по жёсткой сетке вместо контура)
- Обрезать Ксюшу ещё плотнее (убрать лишний прозрачный отступ по краям)
- Скорость ходьбы и бега — снижать несколько раз подряд, до очень медленного значения
- Добавить плавности ходьбе: смена кадров должна быть привязана к пройденному расстоянию, а не к времени (иначе на медленной скорости выглядит как "скольжение")
- Снизить частоту смены кадров ходьбы (шаг крупнее)
- Немного добавить скорости обратно после того, как снизили слишком сильно
- Увеличить персонажей на 25% (при увеличении дороги в 2 раза)

2. ОСНОВНАЯ ДОРОГА / МИР
-----------------------------------
- Деревья, кусты, камни — на задний план (сейчас перекрывают порталы и надписи)
- Персонажи — между сценографией и текстом по z-index (не должны прятаться за деревьями)
- Подписи локаций — с заглавной буквы
- Убрать "обрыв" дороги при подходе к самому началу пути (нужен запас слева)
- Сократить саму карту (уменьшить расстояния между точками маршрута)
- Промпты и вставка текстур: деревья/кусты/трава/камни по сезонам (весна/лето/осень/зима), реальный сезон определяется по месяцу в дате каждой точки, а не по циклу глав
- Отдельный набор "особых" ориентиров (домики, необычное дерево/цветок) — редко расставленные, домики на заднем плане (дальше деревьев)
- Текстура самой тропы (дорожки) — несколько попыток с бесшовностью; в итоге сделать вообще без сезонности, единая текстура на весь путь
- Сузить саму дорогу (тоньше по высоте)
- Позже — увеличить дорогу (и всё на ней) в 2 раза, но выровнять по высоте с порталами и светлячками (опустить вниз, координаты маркеров не трогать)
- Плавный переход в зимнюю зону: снег должен начинаться издалека (заранее), а земля под ногами меняется только ближе к самой зоне — без резкого рывка

3. ТАБЛИЧКИ / ПОДСКАЗКИ "E — ..."
-----------------------------------
- Текст с описанием точки должен появляться, когда Никита заходит в точку, и пропадать, когда Ксюша (идущая следом) её покидает — а не по абстрактному радиусу
- Убрать длинное текстовое описание на карточках с комиксом — оставить только дату (с заглавной буквы месяца)
- Убрать конкретные подписи вида "E — сугроб" — везде должна быть универсальная подпись "E — нажать"
- Подсказки "E — ..." должны появляться только когда персонаж уже реально зашёл/подошёл вплотную к точке, а не заранее издалека

4. ПОРТАЛ "ГРУЗИЯ" (top-down комната)
-----------------------------------
- Сделать полноценную top-down локацию с ходьбой и взаимодействием (вместо плоской картинки)
- Персонаж сверху — сначала кружок-плейсхолдер, потом заменить на настоящий спрайт Ксюши (перегенерированный в отдельном ракурсе, 4 направления)
- Пол/фон комнаты — сначала тайлы, потом заменить на полноценную цельную нарисованную сцену (горнолыжный склон, домик, пруд, подъёмник)
- Коллизия: персонаж должен ходить только по нарисованной (размеченной вручную) дорожке, не проваливаясь за её пределы
- Три интерактивные точки: "ларёк с водой", "Ксюша после занятия", "сугроб" — расставить по координатам, отмеченным пользователем на скриншотах
- Заменить эмодзи-иконки точек на настоящие пиксель-арт иконки (бутылка / следы / фигура в снегу)
- Иконки: уменьшить в 1.5 раза, поднять на 15px, затем ещё на 10px, затем ещё на 5px, сместить на 7px влево
- Стартовая позиция Ксюши в комнате — сместить на 25px вниз
- Добавить "жизни" в передвижение по комнате:
  - покачивание тела при ходьбе (как на дороге)
  - следы на снегу (двумя дорожками, поочерёдно)
  - лёгкое облачко снежной пыли у ног при каждом шаге
  - едва заметный параллакс фона при движении камеры
  - короткая тряска экрана при входе в портал
- Ходьба ногами влево/вправо — использовать те же самые проверенные кадры анимации, что и на основной дороге (просто зеркалить для другого направления), а вперёд/назад оставить как есть (один кадр с покачиванием)
- Увеличить картинку (пол/фон) комнаты и персонажа в ней, плюс увеличить сам комикс на карточке
- Скорость персонажа в этой локации — снижать отдельно от дороги, в несколько раз

- Комикс должен открываться в карточке по нажатию E прямо в этой же локации (был баг: карточка отображалась "под" комнатой из-за z-index — исправлено)
