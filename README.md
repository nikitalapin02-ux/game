# Наш Путь — игра-предложение

Веб-игра по мотивам совместной истории Никиты и Ксюши: дорога-таймлайн
с 2017 по 2026 год, порталы-локации по путешествиям и финальная сцена
предложения.

## Структура репозитория

- `source/characters/` — спрайт-листы главных героев (Никита, Ксюша, Макс, Шемрок) из старой версии
- `source/legacy_game/` — старая рабочая версия игры (reference only, дизайн переделывается с нуля)
- `docs/scenario.md` — таймлайн истории по главам (71 точка, 13 порталов)
- `docs/wishlist.md` — сводка всех пожеланий по игре из предыдущих обсуждений
- `assets/locations/` — сюда добавляются новые ассеты локаций (в работе)

## Статус

Новая версия игры в разработке — актуальный статус см. в PR/коммитах.
